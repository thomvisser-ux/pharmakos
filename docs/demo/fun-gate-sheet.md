# Playtest sheet

Thank you for playing. This sheet says how to start the game, turn on Playtest mode, and send what it
recorded. The person who sent you this sheet will tell you how you get the game and where to send the
file.

## Start the game

1. Extract the whole zip into a folder of its own, and keep its files together.
2. Run `Pharmakos.exe` in that folder. The build is unsigned: if Windows says "Windows protected your
   PC", choose "More info", then "Run anyway". The zip's `README.txt` says the same.

## Turn on Playtest mode

3. In the lobby, tick **Playtest mode**. It is off every time the game starts, so tick it each time.
   While it is on, the lobby says what it keeps: counts and times, never a playbook, a draft, a
   notebook, a path or a name.
4. Press **New match: Probation**. You play one match of three rounds against the built-in opponent.
   Your planning time (the Lull) has no countdown: take what you need. If you press Ready with nothing
   submitted, the game files a safe playbook for you and says so.

## Send the bundle by hand

5. When the match ends, the playtest survey asks three questions. Answer them, press **Export playtest
   bundle**, and choose where to save the file.
6. The file is a zip of four files: `survey.json`, `metrics.json`, `diagnostics.log` and
   `manifest.json`. Your last answer goes in exactly as you wrote it, so **read the four files before
   you send them**.
7. Send the file by hand. The game uses no network: nothing leaves your computer unless you send it.
