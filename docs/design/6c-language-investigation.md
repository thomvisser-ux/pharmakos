# Item 6c: shared plan format and script language for tiers 2–4

## 1. The decision in five lines

1. Ship **Zero-Engine's skeleton** — one JSONC artefact, one external-Deno TypeScript SDK, no script runtime inside the game — but justified on maintenance, licensing and packaging grounds, because the Windows/MSVC objection to embedding was **refuted by both refuters** and must be struck from the record.
2. Graft four things the panel found: one-command agent onboarding (`kit init`), offline snapshot iteration, a generated plan-vs-outcome record, and `run_script` as the primary MCP tool.
3. Fix what all four proposals got wrong: a gameplan is bound to a round, a seat and a map, so "pastes unchanged" is **lexical, not operational**. Budget the rebind, make templates (not concrete plans) the shareable unit, author every shipped sample late-bound.
4. Deno is an **optional install component** at a fixed absolute path — never bundled into the base installer, never resolved through PATH. Bundling inherits Deno's antivirus reputation and macOS nested-binary signing for no gain in the failure class it was meant to fix.
5. Delta **+1.3 wk**; the +2 wk embedded-language reserve and the +1.5 wk slice-6 in-game runtime are released. G6 becomes a 0.5 wk cold-start-and-paste spike moved forward to wk 36.

## 2. Recommended stack, tier by tier (Recommended)

### Tier 2 — the artefact
**Format.** JSONC = canonical proto JSON + `//` and `/* */` comments, snake_case keys, typed param nodes as a proto oneof (`{"param":"x"}` / `{"literal":3}`). This is the only file format in the product.

**Snake_case, both mechanisms.** Set explicit `json_name = "<snake_name>"` on every `gp.v1` field (buf lint enforced, auto-fixing) **and** pass `pbjson_build::Builder::preserve_proto_field_names()` on the Rust side. The two mechanisms disagreed between proposals; verification split (see §5, row 11), and this combination is correct under either reading while also making any third-party generated client emit snake_case.

**Schemas: two dialects, not three.** `gameplan.draft7.json` binds to the VS Code editor via `json.schemas` (no `$schema` key inside plan files); `gameplan.2020-12.json` serves MCP tool schemas. **Drop the flattened constrained-decoding dialect** — Anthropic's SDKs already perform the constraint-stripping and `additionalProperties:false` transformation automatically, and AirGap has no consumer for it (tier-4 seats are interactive Claude Code sessions that never expose `output_config.format` to the game; the term appears nowhere in the design doc).

**Tooling.** `jsonc-parser =0.33.2` in Rust is authoritative, used by the editor, the CLI and the gateway. Editor round-trip is CST-preserving (comments and key order survive Save).

**Two schema-level fixes, both day-one and both impossible later.** Add `AUTHOR_KIND_SCRIPT` / `PLANNER` / `SAFE_PLAN` to `header.author_kind` before any golden ships (§1.9 rejects unknown enum values with E0003, so a pre-enum build splits the corpus). Replace `plan_hash = xxh3(prost bytes)` with `plan_fingerprint_v1` over RFC 8785 canonical JSON, with `schema_version`, `rules_hash` and `verifier_version` mixed in, plus a stored `plan_hash_alg` tag.

### Tier 3 — the script
**Language: TypeScript. Runtime: external Deno, optional component.**

The runtime ships as a separate "Scripting Tools" download extracted to `<install>/runtime/deno(.exe)` and invoked **by absolute path only, never PATH**. Absolute-path invocation is what deletes the `spawn ENOENT` class; bundling into the base installer does not add to that and does add: a second signed binary per OS, macOS `Contents/Helpers` plumbing with a JIT-entitlements collision, and inheritance of Deno's AV reputation — Microsoft Defender quarantined the *signed* deno 2.9.6 Windows zip as `Trojan:Win32/Cloxer` between 29 and 31 August 2026, two weeks before this assessment.

**SDK — a folder, no package manager, no build step.** `types.ts` (generated by ts-proto, **checked in**, CI-diffed on regeneration), a ~250-line hand-written JSON-RPC `client.ts`, a ~120-line vendored `jsonc.ts` golden-tested against the Rust parser, `plan.ts` (`loadPlan`/`savePlan`/`assertPlan`), eight template scripts, ten worked examples, `deno.json`, `SKILL.md`, `AGENTS.md`.

**The ts-proto option string, corrected.** Execution testing showed `onlyTypes=true,snakeToCamel=false` alone does **not** deliver the paste property. Use:
`onlyTypes=true,snakeToCamel=false,stringEnums=true,enumsAsLiterals=true,unrecognizedEnum=false,useOptionals=all` and pin `protoJsonFormat` explicitly. Accept the cost: `useOptionals=all` means TypeScript no longer catches a missing required field — `assertPlan()` plus a new verifier diagnostic (E0012, oneof with multiple members set) covers the residue, and `verify_plan` remains the authority.

**Deno invocation, corrected.** `gamectl script run` passes `--check` **unconditionally** (`deno run` does not type-check; the "default-on checker" framing in both proposals is wrong — owning the command line is what makes it on-by-default for our users), plus `--no-prompt` explicitly (TTY suppression keys on stdin/stderr, not stdout), and `--allow-net=:PORT` rather than `--allow-net=127.0.0.1:PORT` (allow-side host matching is literal, so `ws://localhost:PORT` would be refused).

### Tier 4 — the agent
`gamectl mcp --seat s2` over stdio (rmcp). **Ten coarse tools**: `run_script`, `get_briefing`, `get_outcome`, `verify_plan`, `submit_plan`, `render_plan`, `instantiate_template`, `save_notes`, `get_schema`, `await_next_event`. `run_script` is primary — it lets an agent do code-mode in a host with no shell and structurally forces verify-before-submit. The other ~18 gateway methods are `gamectl --json` subcommands.

`gamectl kit init --agent both` writes `AGENTS.md`, `CLAUDE.md`, `.mcp.json`, `.codex/config.toml`, `deno.json`, `.vscode/settings.json`, a starter `plan.ts` and a `SKILL.md` folder into the agent's working directory (with `--dry-run` and merge-don't-clobber). This is the take-off mechanism.

`get_outcome` / `round-<k>.outcome.json`: per route step {planned, started_at_ms, completed | failed(reason) | not_reached}, per handler {fires, suppressed_by_cooldown}, estimator forecast vs actual, fingerprint back-reference. A sealed Push gives the author no other feedback channel, and it doubles as the human recap.

`gamectl snapshot export --round k` + `verify --snapshot ./snap.json` gives an unmetered, offline, clock-free error loop. This is the highest-leverage addition for *hand* authoring, not just agents.

### Execution model
**External process only in v1.** One long-lived Deno process per match per script seat, spawned by the lobby exactly as an LLM seat is, looping `await_next_event → get_briefing → makePlan → verify_plan → submit_plan`. Reasons, in order:

1. The sealed Push makes producer determinism irrelevant — the replay's input alphabet is seed + plan blobs + log, so a script is never in a replay by value.
2. The zero-toolchain opponent is already funded: the deterministic built-in planner at Easy/Normal/Hard.
3. Permanent security-boundary obligation over 20 months (isolated-vm in maintenance mode with a critical advisory; Screeps shipped an RCE via console-log rendering in January 2026; Factorio deleted `io`/`os` and still ate a Lua-bytecode RCE; Robocode's sandbox invalidated by JDK 24).
4. rquickjs 0.13.0 is a 0.x crate that shipped breaking `unsafe` API changes **and** a memory-safety fix in exactly the FFI surface a game would use (#736), five days before this assessment.
5. Licensing: per FSF guidance an in-process interpreter's bindings and prelude would have to be moved into the permissive tree; external processes speaking a wire protocol are mere aggregation and clean by construction.

**Not** MSVC risk. That leg is false and must not appear in the decision record.

**Seams reserved at ~zero cost:** `AUTHOR_KIND_SCRIPT`, `meta.script_ref {name, version, hash}`, the existing `wasm_commander` oneof slot, and a reserved field number for a future `mid_push_commands` stream.

### The exact segue path — every conversion named

| Boundary | Conversion |
|---|---|
| Editor → tier-2 file | **None.** The editor's model *is* the canonical JSON dictionary; CST write preserves comments. |
| Template → plan | `instantiate_template(id, params)` — existing Rust, shared by editor, planner and agents. |
| Tier 2 → tier 3, **load** | `loadPlan(path)` — JSONC parse. One new SDK function (the Rust parser is authoritative; the TS mirror is golden-tested against it). |
| Tier 2 → tier 3, **paste** | **Zero characters change.** `gamectl script new --from plan.jsonc` wraps the bytes in `const base: Gameplan = {…};`. Valid because JSON is a syntactic subset of ECMAScript in *expression* position since ES2019. |
| Script → tier 2 | `gamectl run-script --emit` — canonical pretty-print. Lossy only for comments the script did not itself emit. |
| Tier 3 → tier 4 | **None.** The agent edits the same `plan.ts` and calls `run_script`. |
| Plan mutation / prose / share | `patch_plan` (RFC 6902), `render_plan`, GP1 string — all existing Rust. |
| **Any round / match / map boundary** | **Rebind** — see below. This is the one real conversion and no proposal named it. |

**The rebind.** A saved plan carries `header.seat/round/snapshot_id`, `meta.beacon_tags` bound to ids, `meta.waypoints` bound to voxels, every `BeaconRef{beacon_id}`, every absolute voxel, and build/structure anchors that are bare Voxels with no late-bound form. Within a match this fails loudly (E0401/E0410). **Across matches it fails silently and wrongly**: `b_01` almost certainly exists and resolves to a *different* beacon; a stale voxel in `move` produces only W0703, which does not block, after which the default `on_fail: SKIP` makes the step vanish. The plan carries no match or map identity at all.

Three cheap fixes, and the first two are needed for OQ-7's one-click "resubmit last round's plan" regardless of scripting:
- **Gateway stamps `seat`/`round`/`snapshot_id` at verify/submit**, making the header output-only. Tier-a rebind becomes zero work, and the fingerprint stops being perturbed by the round number.
- **E0401/E0410 carry a generated suggestion patch** proposing the best-matching live beacon (mandate, tag, nearest), applicability `maybe_incorrect`. Rides the existing `patch_plan` + editor "Fix" path — no new API.
- **`extract_template(plan)`**, the inverse of `instantiate_template` (~one screen of Rust), for cross-match and cross-map reuse.

**Consequences for sharing:** scope the GP1 share string to **templates** in v1 (the design doc's own §4.1 wording already says "offline sharing of templates"); a concrete plan gets a distinct prefix and is treated as match-local on import. Author all 8 templates, all goldens and all SDK samples **late-bound** — selectors with explicit `none_policy: SKIP_STEP`, no literal `beacon_id` or `voxel` outside declared params — enforced by a CI lint. §6.1 and §6.2 of the design doc are currently counter-exemplars that would teach agents the wrong idiom.

## 3. Why this beats the alternatives

Summed judge totals: **Zero-Engine 268**, Takeoff 256, Subtraction 252, Workshop 193. Judges 1 (solo-dev maintenance) and 3 (game designer) ranked Zero-Engine first; judge 2 (agent seat) ranked Takeoff first but explicitly wrote that the right move was "Zero-Engine's skeleton … graft Takeoff's three operational pieces onto it." All three converge on exactly the recommendation above.

Zero-Engine wins on four things nothing else has: generated types **checked in with a CI diff gate** (turning ts-proto's four-minors-a-year cadence into a reviewed chore rather than an ambient dependency); a **CI paste gate** that wraps all 18 goldens as `const p: Gameplan =` and runs `deno check`, making the owner's "no complex conversions" requirement a red build rather than a claim; an **offline gate** proving the SDK really has no dependencies; and a **pre-committed abort ladder** so G6 cannot re-litigate the language.

It also avoids the two decisive errors elsewhere. Subtraction hand-writes a protobuf→TypeScript emitter to save one build step — unbounded owned code on the critical path of a schema with recursive condition trees, and its own downsides list concedes the calculus flips. Subtraction also folds `gamectl` into the game executable, which judge 2 showed is likely broken on Windows: Godot exports are GUI-subsystem (hence Godot's own Export Console Wrapper), so `gamectl --json | …` and `gamectl mcp` over stdio would return with nothing on stdout. Takeoff is the same architecture plus packaging at three times the delta, and pins the project to two vendors' agent-config file shapes.

On verified claims: the paste property survives (ES2019 Stage 4, confirmed by execution) but only with the corrected ts-proto option string; `deno check` offline survives; **the MSVC objection does not** — it was refuted by both refuters, so Workshop's embedded proposal loses its cheapest rebuttal and must be beaten on maintenance instead, which it is.

## 4. Alternatives, with downsides

**Candidate B, embedded TypeScript (Workshop).** Now stronger than the panel scored it: the MSVC objection is refuted, `Context::custom` sandboxing-by-omission is the correct construction, the `ScriptHost` trait with a working Boa adapter is genuine insurance, and — unscored by any judge — an interpreter statically linked into the gdext cdylib has **zero incremental signing cost**, because in-process code inherits the host executable's entitlements, and a non-JIT interpreter does not trip the RWX heuristics that catch Deno. *Downsides:* +3.5 wk; a solo dev becomes the permanent security boundary for foreign code; two JS engines in parity for the project's life; the benefit it buys (zero-toolchain scripted seat) is already funded by the built-in planner, and the other benefit (script sharing) is speculative 20 months before a community exists — which the owner's own rule sends to the roadmap. Its own risk list concedes the pack-importer UI is what a solo dev will cut, and if cut the whole spend is wasted.

**Candidate A, JSONC + Starlark/Python.** *Downsides:* eliminated on agent-authoring grounds. Starlark forbids exactly the Python idioms LLMs emit by default (recursion, `while`, classes, `try/except`, `import`) and has no local type checker, so failures look like valid Python that the interpreter refuses. starlark-rust offers no API-stability promise. Python-as-primary loses the paste property (`true→True`, `null→None`) and has no default-on offline verifier. Python remains correct as a *generated secondary* client — one `datamodel-code-generator` invocation emitting TypedDicts, plus stock `ParseDict(ignore_unknown_fields=False)` for a free strict check — and should ship when someone asks.

**Option C, JSONC only, language deferred.** *Downsides:* this is what the owner's "custom/scripted depth goes to the roadmap when in doubt" rule selects literally, and no proposal defended it. It is also the recommended **fallback**, not the recommendation: if G6 fails, tier 3 collapses to `gamectl --json` + JSON Schema + docs and the agent writes whatever language it has. The cost of deferring is that the tier-2 artefact ships without a proven consumer, so the paste property is never tested against a real SDK and the schema hardens around an untested assumption.

**JSDoc-typed plain JavaScript (new, from the panel).** Verified empirically: `/** @type {T} */` on the declaration gives **byte-identical** diagnostics to TypeScript, `deno check --check-js` restores the offline verifier with one config line, and it deletes the type-stripping transform (21 crates) from any future in-game path while making in-game and external bytes literally identical. *Downsides:* its headline advantage is load-bearing **only if an embedded runtime is retained**, which this recommendation rejects; and there is no published benchmark of LLM code-generation quality on JSDoc-annotated JS — genuinely unmeasured, not inferable from the TypeScript numbers. If the embedded question is ever reopened, reopen this with it. Note the panel's proposed syntax was wrong: the *cast* form `/** @type {T} */ ({…})` silently accepts a plan missing a required field.

## 6. Build-plan delta, G6, checkpoints and pivot rules

**Weeks.** Base (Zero-Engine) +0.5. Grafts: `kit init` +0.2, `get_outcome` +0.4, snapshot export +0.15, `run_script` +0.05. Rebind (header stamping + rebind suggestions + `extract_template`) +0.5, of which ~0.3 was already owed to OQ-7. Late-bound sample authoring + CI lint +0.2. Licence headers +0.1. Third schema dialect dropped −0.2. **Net ≈ +1.3 wk**, against which the +2 wk embedded-language reserve and the +1.5 wk slice-6 in-game runtime are both released — roughly **−2.2 wk against the worst-case plan**.

**Separate, not a 6c cost, and currently unbudgeted: packaging and code signing, ~4.0–5.0 wk** (Windows ~1.5, macOS ~2.0–3.0, Linux ~0.5). The macOS leg has a hard prerequisite with lead time — a Mac or a macOS CI runner — because Godot cannot sign a GDExtension build off-Mac at all. Raise this now; it is larger than the entire scripting decision and cannot be discovered at week 57.

**G6, redefined and moved forward to wk 36** (immediately after the fun gate, where changing tack is nearly free), 0.5 wk. "Script runtime" as a spike is **cancelled**. Six pass/fail criteria:

1. **Paste gate.** All 18 golden `.gameplan.jsonc` files, wrapped verbatim as `const p: Gameplan = <contents>;`, pass `deno check` with zero errors.
2. **Offline gate.** With the network adapter disabled, `deno check` and `deno run` succeed on 8 templates + 10 examples. One stray `jsr:`/`npm:` specifier fails this.
3. **Casing round-trip.** Rust emission is byte-identical in key spelling to the checked-in files on three OSes; `buffa 0.9.2` agrees as an independent oracle.
4. **Cold start.** From a fresh install, `gamectl seat doctor` goes green in at most **one** user action.
5. **Seat gate.** A scripted seat plays a full 10-round headless scenario against Normal with zero safe-plan timeouts, and never creates `package.json`/`tsconfig.json`/`node_modules`.
6. **Agent gate.** A cold Claude Code session, given only the install directory, submits a qualifying plan in ≤20 tool calls with zero invented method names.

**Abort ladder, pre-committed:** (1) fails → fix the ts-proto option string or the casing, re-run. (2) fails → remove the offending dependency. (4) needs more than one action → reconsider bundling as a *packaging* decision, after costing the macOS and AV exposure. **No failure escalates to embedding a runtime.** Total collapse → Option C: `gamectl` + schema + docs, and the built-in planner remains the toolchain-free opponent.

**Checkpoints and pivot rules.**

- **Wk 35.5, fun gate.** No scripting. Measure: minutes for a non-author to turn a shipped template into a qualifying plan (target <10); comment survival across an editor round-trip (hard pass/fail); whether anyone opens a plan file unprompted. *Pivot:* if hand-editing is worse than the editor on both time and enjoyment, keep the format and shrink slice 8.
- **Wk 36, G6.** *Pivot:* per the ladder above.
- **Wk 60, post-slice-8.** Four arms, same 3 scenarios, 5 matches each, opponent = Normal planner: (a) editor only, (b) hand-edited JSONC, (c) AI-written TS via `script run`, (d) live MCP session. Metrics: win rate; wall-clock to a qualifying plan; `verify_plan` calls before first clean verify; E-code histogram; route-steps-completed-as-planned (this is the number that says whether the plan *language* is expressive enough); artefact reuse between Lulls. *Pivots, written in advance:* if (c) does not beat (b) on **both** win rate and time-per-Lull, cut the SDK to types-only and move scripts to the roadmap. If arm (b) exceeds 3× arm (a) on time, spend the remedy on completion and diagnostics, not on a new format. If `deno check` catches under 30% of what `verify_plan` later catches in (c), the generated types are not earning their pipeline.
- **Wk 65, post-slice-9.** Tool-surface ablation: 10 tools with `run_script`, 10 without, full 27. *Pivot:* if the 27-tool arm wins, re-expand — a config change, not an architecture change. Add a local-model arm, judged on outcome statistics only (LLM inference is not bitwise reproducible at temperature 0).
- **Nightly, standing.** Split in two: a deterministic planner-and-script regression league asserting state hashes, and a separate non-deterministic model-seat exhibition judged on win/loss distributions. Never mix them. Add one assertion the plan lacks: re-run a finished match from its own recorded plan blobs and require the final state hash to match.

**One rule to respect:** three proposals invented a published `verify_budget` count in the briefing. That is an artificial cap and an accounting mechanic, both of which the owner ruled out. Scope it to league and CI matches only; a human or agent in a normal game never meets it.

## 7. Risks and mitigations

| Risk | Mitigation |
|---|---|
| `useOptionals=all` means TypeScript cannot catch a missing required field — the type-checking advantage over Python is narrower than claimed | State the narrow claim in SKILL.md ("catches invented and misspelt fields offline in ~1 s"); ship `assertPlan()`; add verifier diagnostic E0012 for a oneof with multiple members set |
| ts-proto is one maintainer with frequent minors, and its README says `oneof=unions-value` is slated to become the default | Pin `=2.12.3`, vendor the binary, check in `types.ts`, CI-diff on regeneration. protobuf-es is a same-language swap costing an import line, not a script rewrite |
| pbjson frozen on the wire-format critical path | Do not migrate; insure. 18-file golden corpus round-tripping on three OSes plus `buffa 0.9.2` as a CI oracle. Named exit: prost-reflect's canonical JSON, triggered by a prost 0.15 release or a confirmed compliance bug |
| A shared or reused plan silently mis-targets in a different match | Gateway stamps the header; E0401/E0410 carry rebind suggestions; GP1 scoped to templates; concrete plans get a distinct prefix treated as match-local on import |
| Runtime discovery fails on Windows | Absolute path only, probe `<install>/runtime/` first; `runtime_path` override in the per-seat manifest; `gamectl seat doctor` prints the resolved path and the one recovery action. G6 criterion 4 measures it on a clean VM |
| The agent invents a build scaffold | Ship `deno.json` pre-configured; explicit negative instruction at the top of AGENTS.md and SKILL.md; `script run` refuses to start when `package.json`/`tsconfig.json`/`node_modules` appear beside the script, naming what to delete; G6 criterion 5 |
| Anything a script or plan emits into the UI is untrusted text | Escape log lines, plan titles, beacon tags and notebook text. The January 2026 Screeps RCE arrived through console-log rendering, not the VM — and that is true whether execution is in-process or spawned |
| `get_briefing` is not pure in `snapshot_id` (the notebook is mutable during the pause) | Snapshot the notebook at Lull start; record ~8 KB per seat per round in the private replay cache; run the league's double-run check with notebook writes buffered |
| An external script can brute-force the map from its seed | Derive `briefing.seat_seed` from a per-match secret **independent of `match_seed`**; never expose `match_seed` to a seat. xxh3 over a short match seed is brute-forceable offline |
| macOS signing discovered late | Acquire a Mac or macOS CI runner before slice 8; first notarization debugging round budgeted at 0.5 wk (the gdext dylib is the documented failure point, per Godot #81733) |

## 8. Open questions for the owner

1. **Bundle or optional?** I recommend optional, on the AV-reputation and macOS-nested-binary evidence the judges did not have. Judges 1 and 2 both wanted it bundled. G6 criterion 4 decides it empirically; you decide whether one user action is acceptable.
2. **Mac hardware or CI runner — when?** It is a hard prerequisite for any signed macOS release of a gdext project, independent of scripting, and it has lead time.
3. **Does a `best_site {resource, near, constraint}` selector get added?** Without it, expansion and construction are permanently parameter-bound and three of the eight templates can never be fully portable. With it, the built-in planner and LLM seats share one vocabulary.
4. **One clarifying sentence:** scope the decided "no headless or accelerated mode in v1" to *player-facing* AI-only matches. The dev harness already ships `gamectl scenario run` headless, so this is an ambiguity in the record, not a reversal.
