Design specification · codename

AirGap

Nothing that listens can be trusted. Nothing you touch can be taken.

AirGap is an open-source voxel strategy game in which every seat, human or AI, plays in exactly the same way. Players seal orders during a planning pause, then watch the plan play out like a movie. Commanders must physically touch a beacon to change it. Opponents can be LLMs working through a documented local API, the built-in planner, or a person using the in-game plan editor.

What changed since draft 4

  • New fifth mandate, Survey, fields scouts and refreshes sightings before they expire. Defend gets a picket; Build owns repair and reclaim drones.
  • The core is a fortified Stake with its own autocannon, and spawns sit a guaranteed distance apart.
  • Commanders can be hunted: Attack gets an enemy-commander selector, and Defend can guard your commander.
  • Final audit credit for a destroyed asset is split by damage dealt, not given to the killing blow.
  • Each seat has a private notebook that carries across Lulls.
  • LLM seats are interactive Claude Code or Codex sessions. "Your agent" joins your own session; opponent windows are locked down by hooks. Headless runs move to the roadmap.
  • A four-tier AI ladder sets build order: playable without AI → hand-editable sample files → scripting API → live LLM conduit.
  • The skeleton and fun probe no longer need MCP or an LLM. New slices 8 (scripting) and 9 (live conduit).
  • Still open: the shared file format and script language, plus art, audio and three small rules.
  • Build plan grows to 71 weeks. Probe at week 17.5, fun gate still at week 35.5.

1Vision & scope

AirGap is both a playable game and an AI platform. It has to be fun and spectacular to watch, and it is built so that AI control is part of the design from the start rather than added later. One developer builds it with AI coding agents, so scope discipline is a design constraint in its own right.

Every seat is equalHumans, LLM agents and the built-in AI plan with the same schema and pass the same verifier. During play nobody has live control, so every seat is on equal footing.
Sealed orders, then the moviePlans are sealed in a timed pause. The world then runs for up to 8 minutes while everyone watches.
Touch to changeChanging a beacon requires the commander to travel there and interface with it. Commander time is the real currency.
The world is voxelsDestructible terrain with a height cap. Craters, breaches and growing crystal spires are what spectators come for.

v1: the sandbox

  • Decided A local host for up to 3 seats in free-for-all: one human plus up to two AI seats, or all AI. It comes with a basic attack/defend kit and generated maps.
  • Beacons run built-in operators only. The customization in v1 is gameplans, mandates, settings and capability structures, all reachable through the API.
  • A documented local API and MCP server, so coding agents such as Claude Code can plan turns and help players write plans. Draft 5 Built in this order, following the AI ladder:
    1. Playable without an external AI: built-in planner, plan editor, templates, Probation.
    2. Hand-editable samples: templates and sample scripts as local files you copy and edit. Open format and language.
    3. Scripting API: published docs aimed at AI-assisted script writing, plus an official SDK.
    4. Live conduit: MCP for interactive Claude Code or Codex sessions, either your own agent or AI opponents.
  • Native Godot client with a plan editor, spectator camera, event timeline and highlight scrub. Decided Also a Ledger "Probation" match for newcomers, save and resume at Lull boundaries, and an opt-in playtest mode.
  • Decided Windows and Linux builds are first-class; macOS is best-effort and unsigned. Distributed through GitHub Releases and itch.io.

Not in v1

  • Custom operator programs, reprogramming, a custom quartermaster, and WASM commanders. These arrive one per version. Roadmap
  • Voting, internet multiplayer, the web spectator, the RL (Gymnasium/PettingZoo) interface, flowing water, and manual commander control. Roadmap
  • Decided Human-vs-human play, teams, beacon capture, Citations, grid islands and batteries. Roadmap

Decided Caps rule: no artificial caps. A limit exists only where it is technically necessary, and each one is explained coherently in the story. Examples:

  • The unit ceiling is the power a map's vents can supply.
  • Plan size is the Ledger's seal inspection.
  • Decided A beacon's reach is where it can see or relay orders.
  • Decided Award payouts come from the Ledger's fixed fund.
  • Decided A Dispatch's length is the brief transmission window.

2World & lore

Decided AirGap is set in the Handfast world: grim and near-future, lightened by bureaucratic humour in the Ledger's voice. This is original IP and borrows no franchise names.

Decided AirGap is a codename only: no logo, domain or store page. A 2026-09-13 quick search found the Steam game "Interstellar Airgap" (2021), AIRGAP software trademarks held by Airgap Networks/Zscaler and Transcend, and a 2025 board game called "Quorum". A final title and faction names, plus a professional clearance search, come before anything goes public. All world terms live in the table below, so a rename is a find-and-replace.

By 2061 humans and machine minds share every grid, farm and factory. Then the Overwrite shows that any machine that listens can be rewritten by a cleverly shaped signal. Civilisation splits along a line of belief, not species. The war that follows ends in the Pall, a sky of ash and dust that has not lifted in a generation. Solar is a memory, so every cell lives on geothermal heat: the deep bore under a founding Stake, the shallow bore that keeps each key-core's seal lit, and the vents worth fighting over. The Quorum is a sovereign mind governed by the votes of millions of human citizens. The Handfast Line is made of human cells and the minds sworn to serve them, and it refuses to be ruled by anything it can't unplug. Both sides field humans and AIs. Nobody gives orders over radio any more: a Keybearer carries an air-gapped key-core and presses it to a Stake by hand. The only thing both sides still obey is the Ledger, a pre-war armistice engine that pays every cell, fines the incompetent in deadpan memos, and inspects every set of sealed orders.

The frame explains the core mechanics:

  • Mirror matches. Each seat picks a banner, which is cosmetic, and feuding cells explain any mix of seats.
  • No live control. Radio silence during the Push is the reason plans are sealed.
  • Data-only radio. Stewards may listen, but they have no pathway that lets them obey.
  • Awards and safe plans. The Ledger gives these out; a safe plan is "a standing order filed on your behalf". Citations return after v1.
  • Decided Darkness and power. The Pall explains why there is no solar, why vents are worth fighting over, and why lit domes and brownouts are so visible on screen.
  • Decided Licences. Capabilities are Ledger licences, earned by meeting its conditions.
  • Decided Bores. Only a seat's founding core sits on a deep bore with spare heat. Other key-cores tap just enough to keep their own seal lit. When a core falls, its bore collapses for good.
  • Decided Dispatches. As the seal closes on the Push, each network gets one open-air transmission. Stewards "speak on the air, never obey it", which is also why a Dispatch is only ever read as data.
  • Decided Ruins and the final audit. When a seat's last seal goes dark, the Ledger voids its licences and its structures become ruins. At the round limit, the Ledger credits what you hold and what you broke.

3Match structure

LobbyUp to 3 seats (≤1 human): human, built-in, or your coding agent. Host settings, seat tokens, resume a save
LullPlanning pause: host-set, default 5 min, first Lull 10 min. Ends early when all seats are ready
PushPlay segment, about 3 min early growing to 8 min. No control
Recap≤ ~60 s, skippable: awards and 3 highlights. Timer not running
Match endOne seat left, or the round limit (default 6, about 75 min)
  • Decided Seats: free-for-all with up to 3 seats: one human plus up to two AI seats, or all AI, on localhost. No teams in v1, but a team_id field is reserved. The human alone decides speed-up and skip. Draft 5 A human working with their own coding agent ("Your agent") is still the one human seat. Decided An AI-only match uses the normal client flow in realtime, with a spectator camera in place of the human. Pace controls and headless runs are Roadmap, added when bulk AI testing needs them.
  • Decided Match end: a seat's first beacon is its core. A seat is eliminated when it has no beacons left. The match ends when one seat remains, or at the host-set round limit. The round limit defines the match phase used by segment growth. Decided Default length is about 75 min: round limit 6, 5-min Lulls (first 10), Push growing 3 → 8 min. Licence triggers, awards and segment growth are tuned for 6 rounds.
  • Decided Save and resume: the host can save during any Lull, from the frozen segment-end snapshot, and resume from the lobby. Seat tokens are reissued, and LLM seats simply relaunch. Saves are stamped with the rules hash and verifier version, and won't load on a mismatch. They contain every plan and draft, so they live in the private match cache. No saving mid-Push.
  • Decided Probation match: a lobby preset for newcomers: the human vs one Easy built-in, 3 rounds, untimed Lulls. The Ledger issues contextual memos from deterministic triggers (a dark Stake, first death, a power shortfall, first licence), and the first Lull opens the template wizard with a guided pick. It doubles as the fun-probe setup.
  • Decided Round-limit winner, "the final audit": score = value held at the final tick ($ plus build cost of your beacons, structures and units) + build cost of enemy assets you destroyed. Draft 5 Credit for each destroyed asset is split between seats in proportion to the damage each dealt since it was last at full HP, so a last hit steals nothing. The recap shows "shared kill". It is shown live in the standings. Hoarding alone doesn't win. Risk kingmaking and farming the weakest seat in 3-way FFA.
  • Decided Elimination:
    • When a seat's last beacon falls, its units disband on the spot and its structures become neutral ruins. Decided Any seat's reclaim drones can salvage ruins within their beacon's reach for $.
    • An eliminated human becomes a spectator with a full-map view, and can end the match at any time. Standings freeze at that tick and the recording is saved.
  • Decided Planning pause: all seats share one timer, set by the host from 3 min to untimed. The default is 5 min, and 10 min for the first Lull. Each seat plans only from its own fog-of-war view and sees who is ready. AI seats wait by long-polling.
  • Decided Segment length: starts short and grows with the match phase, up to 8 minutes by default. The host can configure it. Tuning growth curve.
  • Decided During play: no manual control of anything. The human gets an own-fog camera, a free camera and a follow-commander view, a live event timeline, and 2–4× speed or skip. Decided There is no live chat. Seats talk only through Dispatches, shown as a ticker when the Push starts. The auto-director camera is Roadmap.
  • Decided Push camera: while the human's seat is alive, the camera and director show only that seat's vision, the same as the AI seats' get_segment_feed. The full map unlocks when the seat is eliminated or the match ends. The host's casual setting gives every seat no-fog during the Push (camera and feed alike); planning knowledge stays fogged, and the match is unranked.
  • Decided Recap: its own phase between the Push and the Lull. The Lull timer starts when the recap ends or is skipped. The planning snapshot is frozen at segment end. During the Lull, a side panel re-plays and scrubs highlights while the timer runs.
  • Decided Plan secrecy: opponents never see your plans. Every round should be completely different, so there is no "reuse last plan" shortcut. Secrecy is enforced by the API and UI; on a local host it cannot be cryptographic.
  • Decided Timeout or failed verification: beacon configurations stay as they are, and the built-in planner files a safe plan for that seat.
  • Risk Whether up to 8 minutes of play with no control is fun is the biggest unmeasured risk. Decided A fun probe tests it at the end of the walking skeleton (Draft 5 week 17.5, human vs built-in opponents only), and the fun gate decides go or pivot after slice 3 (week 35.5). See section 17.

4Commander

  • Decided The commander is the only unit a seat drives directly, and only through its gameplan. It is weak and killable.
  • Decided Mobility: a hover-walker at a fixed speed that climbs 1-voxel steps. Terrain, walls, craters, ramps and bridges shape its routes.
  • Decided Death: respawns after a delay (for example 30 s, growing with each death) at the core. Decided If the core is gone, it respawns at the surviving beacon nearest to where it died. Beacons keep running, but nothing can change them until the commander returns. Death also interrupts any visit in progress. Gameplans must include an on_death block. Tuning delay curve.
  • Draft 5 Hunting: commanders are fair targets and hunting them is a real strategy. Attack can select the enemy commander from its last sighting, and retargets live while any of its units can see it. Defences: routes that avoid known threats, flee rules, on_death, and a Defend beacon guarding "my commander" (section 6). Further counters (armour, decoys, a self-defence weapon) are added only if the nightly league shows hunting dominates. Risk
  • Decided Start: each seat begins with a pre-placed core beacon (Build mandate) in its spawn zone, the commander, 2 build drones, 1 mining drone and $ equal to 2 rounds of BMI. The core's key-core powers that force with some headroom, and a heat vent sits a short walk away. Draft 5 The core is armistice-hardened: high HP and a built-in autocannon powered by its deep bore, so a single early raid can't eliminate a seat. Tuning starting numbers.
  • Decided No remote changes: every change to a beacon happens on site.
  • Roadmap Self-defence weapon, carrying a demolition charge, minimal dig/construct, sensor ping, vehicles with auto-firing defences (earned), and manual control for a full round.

7Economy

Decided The principle: reward good play while giving trailing players a way to catch up and beginners a hand-up. Keep it simple, because accounting is not fun.

ElementRule

Power supplyDecided Seal-only key-cores: a non-core key-core outputs exactly its own beacon's base draw (net zero). Only the core's deep bore gives spare kW. Generators, built for $ by the Build mandate, sit on heat vents, and each map has a finite number of vents. All your spheres form one grid, since the placement rule keeps them connected. No batteries in v1.

Unit ceilingDecided A property of the world, not a rule: a seat can field only what its core surplus and vent Generators can power. Beacon spam adds no power. Map generation keeps total supply within the G3′ segment budget. The engine keeps a hard safety limit far above anything a map can power.

Quartermaster (spend control)

  1. Decided Balances power: when draw exceeds supply, it holds fabricator orders, then applies the brownout order.
  2. Fills operator spend requests by urgency: defend under attack, then repair, units, build, mine.
  3. Shares funds fairly so no single beacon can hog them. The one player lever is the per-beacon low / normal / high priority knob, which is set on site.

Decided You only make it worse on purpose. An existing power shortfall is a warning (W06xx), flagged in plain language in the recap. A plan that adds draw beyond supply (placing a beacon, queuing a structure) is an error unless "allow dormant beacons" is set. Beacons can also be recycled on site for a 50% refund.

Grid islands, where a cut chain splits the grid. Batteries. Custom Quartermaster: pre-installed and verified offline, and can only be switched back to the default during a match.

10Gameplans

Decided A gameplan is typed declarative data, not a script: a route of steps, prioritised rules (gambits), a required on_death block, a required fallback, and Decided an optional public dispatch note. It drives the commander for one segment. Humans, LLMs and the built-in planner all produce the same format. A WASM commander later uses the same outer envelope.

Execution

  • Timing: plans run inside the deterministic sim at 20 Hz. Decisions (rules, step transitions, selector resolution) are taken every 250 ms of game time. Plan times are game milliseconds, never ticks.
  • Order on each decision: reflex first (commander HP ≤ 20%, which can't be disabled), then the first enabled rule whose condition is true, then the current step.
  • When a rule fires: it aborts the remaining changes of any visit in progress (changes already committed stay), runs its body, then resumes as continue, skip step, jump forward, or end route. On continue, the interface step resumes with only the uncommitted changes plus a new handshake.
  • Segment end: the plan stops. Nothing carries over except the world itself.

Every step supports the skip_if, timeout_ms and on_fail guards (skip, abort route, or jump forward), plus a label and a note.

Why a plan survives a long segment without a dry run

  1. Late-bound selectors. For example "my weakest Defend beacon", or "the nearest known enemy beacon seen within 15 min". These resolve when the step starts, then stay pinned for that step.
  2. Rules that interrupt and resume, with explicit resume semantics.
  3. Guards on every step, so steps degrade instead of blocking.
  4. Autonomy on the beacon side, set on site. For example, an Attack launches at 4:00 or on go-code A, so a dead commander doesn't stall it.
  5. A guaranteed tail: the fallback posture (hold, shadow or patrol), and the self-preservation reflex.

Conditions

  • Structure: all / any / not trees, depth ≤4 and ≤24 nodes, integer comparisons only.
  • Knowledge: they read only the seat's knowledge store. Enemy predicates must declare freshness (VISIBLE_NOW or KNOWN_WITHIN ms).
  • Predicate families: clock; commander (HP, position, deaths, recent damage); own beacon (status, HP, under attack, units by role, mandate, powered or dormant, structures, reports since); aggregates; enemy knowledge (units near, beacon known, structure near); economy (treasury, income forecast, kW supply, draw and headroom); capability licence and structure state; radio coverage; plan state (flags, step reached, rule fired, posture).
  • Deliberately absent: enemy plans, enemy treasury and mandates, unseen positions, enemy intent, and randomness.

Termination guarantees

Every plan halts. These limits are technical (bounded cost and guaranteed termination), and in the story they are the Ledger's seal-inspection rules:

  • Jumps and waits: jumps only go forward, and every wait has a timeout.
  • Loops: at most 8 iterations, nesting ≤2, and each iteration consumes time.
  • Decided Size: one plan size budget replaces the separate counts. Steps (loops expanded), rules and their bodies, build targets and protected areas all count toward it. It is sized so FULL verification stays under 50 ms and every seat's rules fit the 20 Hz tick. The embedded gates P1 and the per-rule tick cost set the number. The editor and verifier show a size meter. There are no beginner or expert rule tiers.
  • Rule firing: each rule has a cooldown ≥5 s and fires at most 1–8 times.
  • Hard stop: the end of the segment.

The per-seat evaluation cost is a constant.

11Verifier (seal inspection)

A v1 plan qualifies when all of the following hold:

  1. It decodes strictly at a supported schema version.
  2. It passes every limit and termination rule.
  3. Every reference resolves against the seat's frozen knowledge snapshot, or has a none-policy.
  4. All changes and settings are within range for the built-in operators. Decided Attack targets lie within reach at plan time (sphere, positions seen by the seat's units and structures within the last N minutes, Sensor Spire reveals, relay coverage; Decided unit vision added), and the plan fits the size budget.
  5. It has zero errors. An existing power shortfall is only a warning. Adding draw beyond supply is an error unless "allow dormant beacons" is set.
  6. Its hashes are recorded.

14Built-in planner & computer opponents

A computer opponent is the built-in planner plus the built-in operators. The planner uses the same API traits, snapshot and verifier as every other client. It is deterministic: its seed comes from the match, seat and round, and its budget is measured in evaluation units rather than wall time.

  1. Read the briefing, beacons, known enemies, economy and capabilities.
  2. Compute integer situation features: threat, power headroom, vent sites, expansion sites, capability and attack opportunities, and commander risk.
  3. Fill template parameters with the top-k options, then compose visit goals by greedy insertion by utility per second until the route fills its target share of the segment.
  4. Score utility as defence + economy + expansion + capability + attack − risk, weighted by difficulty. Decided v1 ships the Balanced weighting only; the Turtle, Raider and Economist personalities are Roadmap.
  5. Add the standard rules, then run verify and repair up to 4 times.

Decided Target spread: in a 3-way free-for-all, the planner scores targets partly by how much pressure the other AI seat is already putting on them, so two AIs don't pile onto the same seat by default.

Draft 5 Vision and hunting: the planner places a Survey post when the enemy sightings it needs are stale or missing. It adds a Defend guard on its commander when the commander has died recently, and scores enemy-commander raids like any other target. It ignores the notebook.

Safe plan: leave configurations untouched and move to the safest beacon. If power is short, set up to 2 key nearby beacons to high priority so they brown out last. Otherwise shadow the safest beacon, with the flee and rescue rules. It always qualifies, and get_safe_plan shows the cost of a timeout.

18Roadmap after v1

  • Custom components, one per version (order to be decided):
    • custom operator programs: WASM on wasmi 2.x, fuel-metered, Rust SDK, installed on site, content-addressed
    • the earned reprogramming capability
    • custom Quartermaster
    • WASM commander under the gameplan envelope

    Coding agents help write these through the local API.

  • Voting between rounds, including pity votes and voted capabilities, first with seats only and spectators later.
  • Decided Players: human-vs-human (LAN, then internet), teams via the reserved team_id, more than 3 seats.
  • Decided Conflict and economy: beacon capture, Citations (cosmetic first, fees later), energy charges on individual units for remote operations, grid islands, batteries.
  • Decided Maps: handmade maps and a map editor.
  • Radio: line of sight and relays, jammers, direction finding, satellites. Decided Directed or encrypted Dispatches, interception, live chat during the Push, and Ledger-enforced pacts.
  • Decided Cut from v1: planner personalities (Turtle, Raider, Economist); director camera; gate, reinforced wall and shield block; the expert editor view except selectors (flags, branch and repeat, raw JSON, command palette); timed weapons and combat boosts; pace controls and headless or accelerated AI-only matches; a nightly LLM-seat league.
  • Decided Release and onboarding: signed and notarised macOS builds, a Steam release, mid-Push saves, scripted tutorial scenarios, and networked opt-in telemetry.
  • Structures: the full capability structure catalogue.
  • Commander: abilities, vehicles, and a manual-control round.
  • World: flowing water, internet multiplayer and dedicated servers, and per-mode claim protections.
  • Watching: a web spectator and replay viewer (WASM sim and mesher) and more watch-mode features.
  • Research: an RL interface (Gymnasium/PettingZoo) through custom operators, with batched PyO3 stepping when throughput demands it.
  • Draft 5 AI seats: headless LLM seats with an API key or subscription (claude -p, codex exec, command-template presets) as an alternative to interactive sessions; Claude channels in place of the heartbeat loop; commander armour, decoys or a self-defence weapon if hunting dominates; jammers and decoy beacons against perfect intel.
