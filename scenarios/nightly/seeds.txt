# The nightly adversarial scenarios' fixed seed set (S2's plan, task `night`;
# decisions-log item 144 (6): "a fixed seed set of about twenty seeds").
#
# One seed per line: `0x` and exactly sixteen lowercase hex digits, the
# spelling a scenario's `map.seed` takes. `#` starts a comment. Order matters:
# a seed's position decides the arm's seat, the first, third, fifth... seed
# putting the arm on seat 0 and the others on seat 1 (decision 29), so the
# twenty give each arm ten matches from each seat. The first ten are also G4's
# bar, ten seeded matches of 9 600 ticks on each of the three operating
# systems, in the nightly workflow's `g4` job.
#
# They are the S1 balance check's twenty (crates/gamectl/tests/balance.rs,
# `seeds`): the determinism harness's seed, the scenario files' seed, then
# n x 0x9e3779b97f4a7c15 for n = 1 to 18, so the nightly and the balance
# report play the same maps (S2's plan, task `arms`). Committed, never
# regenerated; crates/gamectl/tests/seeds.rs holds the two lists equal.
#
# A seed changed here is a new night, not a re-run of an old one: say so in
# the pull request that changes it, because every arm's win rate moves with it.
